# Инструкция по разметке изображений (CVAT)

## Настройка
1. Создать задачу (Task) в CVAT; в конструкторе меток выбрать «Raw» и вставить содержимое `annotations/images/cvat_labels.json` (10 видов, у каждого 4 атрибута).
2. Загрузить изображения из `data/images/` с сохранением структуры `<вид>/<файл>`.
3. Для полуавтоматической разметки импортировать `annotations/images/cvat_preannotation.xml` (формат «CVAT for images 1.1»): рамки уже стоят, класс взят из папки вида.

## Правила разметки
1. Рисуется прямоугольник вокруг каждой птицы; рамка плотная, включает клюв, хвост и лапы.
2. Если птица закрыта частично, рамка охватывает видимую часть; отмечается `occluded`.
3. Метка — вид птицы. Если на изображении птица другого вида, метка исправляется, а файл записывается в отчёт.
4. Атрибуты: `sex` (по оперению, если различимо), `age`, `pose`, `plumage_main` (основной цвет оперения). При сомнении ставится `unknown`.
5. Изображения без птицы или с неразличимой птицей помечаются тегом `skip` и записываются в отчёт.

## Примеры
- Правильно: рамка вплотную к синице на ветке, атрибуты `pose=perched`, `plumage_main=multicolor`.
- Неправильно: рамка с большим фоном вокруг птицы; одна рамка на двух птиц.

## Проверка и экспорт
- Проверка: `python src/validate_image_annotations.py annotations/images/cvat_annotations.xml`.
- Взаимная проверка: `python src/validate_image_annotations.py A.xml --compare B.xml` (порог IoU 0,5).
- Экспорт из CVAT: «Export annotations» → «CVAT for images 1.1» и «COCO 1.0»; файлы сохраняются в `annotations/images/`.
